Датчики, учавствующие в регулировании работы компрессоров ССС
Для проведения работ с датчиками, необходимо переключить соответствующий контур регулирования в ручной режим управления.
Для проведения работ с датчиками, необходимо:
1. Перевести антипомпажный регулятор в ручное управление
2. Приоткрыть 42UV-045 для значения dev= +0.12 (для запаса)
3. Включить ключ деблокации антипомпажной защиты, при этом на мнемосхеме должна появиться красная мигающая надпись "Антипомпажная защита выключена"
Датчики, учавствующие в алгоритмах антипомпажной защиты
4. Провести необходимые работы
5. Убедиться, что счетчик помпажных хлопков равен "0", в противном случае произвести сброс счетчика.
8. Выключить ключ деблокации антипомпажной защиты.
